# 系统架构说明

本文档是普通架构说明。项目事实、功能边界和技术路线以 [`../00_project_truth/PROJECT_SSOT.md`](../00_project_truth/PROJECT_SSOT.md) 为准。

## 1. 架构目标

FactoryOffice-Agent 的架构目标不是提供一个单轮问答入口，而是提供一个面向制造业企业办公场景的可控流程系统。

系统需要同时支持：

- 企业文档知识库问答
- 文档上传、解析、切块和向量检索
- 会议纪要转任务
- 设备异常转维修工单
- 质量异常转处理工单
- 采购需求转申请草稿
- 项目周报生成
- 人工审批
- 审计日志
- 企业集成配置、通知投递和签名 H5 审批链接
- 组织同步、SLA 扫描和外部系统同步
- 前后端分离部署

核心设计原则：

- 知识回答尽量基于企业文档，并返回引用来源。
- 正式业务动作先生成草稿，再进入人工确认。
- 工具执行和审批结果必须可审计。
- 默认用数据库和本地 Provider 跑通任务、工单、采购、审批和日志闭环。
- 通过 integrations/providers 和 business_sync_service 预留 OA/ERP/MES/WMS、企业微信、钉钉、飞书和通用 Webhook 接入边界。

## 3. 后端分层

后端位于 `backend/app/`，按企业后端常见分层组织。

| 目录 | 作用 |
| --- | --- |
| `api/` | HTTP 路由层，只处理请求参数、响应结构和路由注册 |
| `core/` | 配置、数据库连接、安全权限、日志和异常处理 |
| `models/` | SQLAlchemy 数据库模型 |
| `schemas/` | Pydantic 请求和响应结构 |
| `services/` | 业务服务层，承接数据库读写和业务规则 |
| `rag/` | 文档解析、切块、Embedding、向量检索和 Prompt 构造 |
| `agents/` | Agent 状态、节点、边、SOP 匹配、补槽和 Trace |
| `workflows/` | 固定办公流程和 SOP 定义，避免完全自由执行 |
| `tools/` | Agent 可调用工具，统一描述、风险和审批要求 |
| `evaluators/` | RAG 和工作流评测 |
| `utils/` | 文件、时间、JSON、ID 等通用工具 |

## 4. 前端分层

前端位于 `frontend/src/`，使用 Vue3 + Element Plus。

| 目录 | 作用 |
| --- | --- |
| `api/` | Axios 请求封装和各业务 API |
| `router/` | 页面路由 |
| `views/` | 首页、知识库、助手、工作流、任务、工单、采购、审批、日志页面 |
| `components/` | 预留可复用组件目录，当前页面直接在 views 中实现 |
| `stores/` | 预留前端状态目录，当前未引入全局状态管理 |
| `types/` | 预留 TypeScript 类型目录，当前类型主要放在 api 封装中 |
| `utils/` | 预留前端工具目录，当前仅保留必要页面逻辑 |

前端设计以企业系统为主，强调清晰、稳定、可操作，不追求花哨视觉效果。

## 5. 数据流

### 5.1 知识库问答

```text
用户问题
  ↓
生成问题向量
  ↓
检索相关 document_chunks
  ↓
按相关度排序
  ↓
构造带引用来源的 Prompt
  ↓
调用 OpenAI-compatible 模型
  ↓
返回回答和引用来源
```

### 5.2 办公流程动作

```text
用户输入业务描述
  ↓
固定工作流生成结构化草稿
  ↓
判断是否需要审批
  ↓
创建 approvals 记录
  ↓
人工 approve / reject
  ↓
批准后调用对应工具
  ↓
写入业务表
  ↓
写入 audit_logs
```

## 6. 人工确认边界

不需要审批的动作：

- 知识库问答
- 查询任务、工单、采购申请和日志
- 生成文档草稿、周报草稿、工单草稿

需要审批的动作：

- 创建采购申请
- 提交维修工单
- 批量创建任务
- 删除知识库文档
- 涉及安全、质量、客户交付或预算风险的动作

## 7. 部署结构

本地部署使用 Docker Compose：

```text
frontend  -> Vue3 前端
backend   -> FastAPI 后端
postgres  -> PostgreSQL + pgvector
```

访问地址：

```text
前端：http://localhost:3000
后端：http://localhost:8000
接口文档：http://localhost:8000/docs
健康检查：http://localhost:8000/api/health
```
