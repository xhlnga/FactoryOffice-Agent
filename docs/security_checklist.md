# 安全检查清单

上线或交付企业 PoC 前，应至少检查以下项目。

## 密钥

- `.env` 不提交 Git。
- `AUTH_SECRET_KEY` 已替换。
- `ENCRYPTION_KEY` 已替换。
- LLM、Embedding、企业微信、钉钉、飞书密钥不写入 README。
- `integration_configs.encrypted_config` 中保存密钥引用或加密值，不保存明文生产密钥。

## 网络

- 后端和数据库不直接暴露公网。
- 回调地址使用 HTTPS。
- CORS 不使用 `*`。
- Webhook URL 禁止默认访问 localhost 和非 HTTP 协议。

## 权限

- 普通员工不能访问全部文档。
- RAG 检索必须带文档权限过滤。
- 审批动作必须经过审批引擎，不允许前端绕过。
- 文档删除、采购、工单等高风险动作必须进入审批。

## 数据

- 上传文件大小有限制。
- 上传目录定期备份。
- 真实企业文档不要放入开源仓库。
- 审计日志保留策略明确。
- 通知失败和外部同步失败可追踪、可重试。

## 运维

- PostgreSQL 开启备份。
- Redis 不暴露公网。
- worker 和 scheduler 有进程监控。
- 失败任务数量有告警。
- 外部系统同步失败不会阻断本地业务主流程。
