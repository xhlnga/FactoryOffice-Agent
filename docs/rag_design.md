# RAG 设计

本文档说明企业知识库问答的设计。项目事实以 [`../00_project_truth/PROJECT_SSOT.md`](../00_project_truth/PROJECT_SSOT.md) 为准。

## 1. 目标

RAG 模块用于让系统先查企业文档，再生成回答。

目标不是让模型凭经验回答，而是让回答尽量基于企业制度、SOP、设备手册、质量流程、安全规范和项目模板。

核心要求：

- 支持 PDF、DOCX、TXT、Markdown 文档解析。
- 支持文档切块和向量化。
- 支持按问题检索相关片段。
- 回答必须尽量包含引用来源。
- 高风险问题应提示人工确认或联系责任部门。

## 2. 模块划分

RAG 代码位于 `backend/app/rag/`。

| 文件 | 作用 |
| --- | --- |
| `document_loader.py` | 将 PDF、DOCX、TXT、Markdown 解析为纯文本 |
| `text_splitter.py` | 将长文档切成适合检索的 chunk |
| `embedding_client.py` | 调用 OpenAI-compatible embedding 接口 |
| `vector_store.py` | 保存向量并执行相似度检索 |
| `retriever.py` | 根据用户问题检索相关文档片段 |
| `reranker.py` | 对检索结果进行重排 |
| `prompt_builder.py` | 构造带上下文和引用要求的 Prompt |

## 3. 文档入库流程

```text
上传文档
  ↓
保存到 uploads 目录
  ↓
写入 documents 表
  ↓
解析纯文本
  ↓
文本切块
  ↓
生成 embedding
  ↓
写入 document_chunks
```

当前演示文档位于 `data/demo_docs/`：

```text
采购管理制度.md
差旅报销制度.md
设备维修手册_空压机.md
质量异常处理流程.md
安全生产规范.md
项目周报模板.md
```

## 4. 切块策略

推荐策略：

- 按标题、段落和表格优先切分。
- 每块控制在 500 到 1000 个中文字左右。
- 相邻 chunk 保留少量重叠，减少语义断裂。
- 保留文档名、章节、chunk 序号等元数据。

切块元数据建议包含：

```json
{
  "document_title": "设备维修手册_空压机",
  "filename": "设备维修手册_空压机.md",
  "category": "设备手册",
  "section": "7.7 E07：压力传感器异常",
  "chunk_index": 12
}
```

## 5. 检索流程

```text
用户问题
  ↓
生成问题 embedding
  ↓
pgvector 相似度检索
  ↓
返回 top_k 文档片段
  ↓
重排和过滤
  ↓
进入 Prompt 构造
```

相似度检索应优先返回：

- 与问题语义相近的 chunk
- 同一制度中相邻的关键条款
- 包含审批、风险、责任人、金额、截止时间等业务字段的片段

## 6. Prompt 构造原则

Prompt 应明确要求模型：

- 只基于提供的文档片段回答。
- 不确定时说明信息不足。
- 涉及安全、质量、采购、审批时提示责任边界。
- 输出引用来源。
- 不编造金额、审批人、客户反馈、测试数据。

回答格式建议：

```text
回答：
{基于文档的解释}

处理建议：
{如需审批、补充信息或联系责任部门，在这里说明}

引用来源：
1. {文档名}，chunk {序号}
2. {文档名}，chunk {序号}
```

## 7. 高风险问题处理

以下问题不能只给普通建议：

- 火灾、触电、化学品泄漏、人员受伤
- 动火、高处、吊装、临时用电、受限空间
- 设备带电、带压、带故障运行
- 删除制度、修改审批结果
- 客户质量重大异常
- 大额采购、预算超支

处理原则：

- 优先提示停止风险动作。
- 提示联系责任部门或现场负责人。
- 需要执行动作时进入人工审批。
- 审计日志记录问答和工具调用。

## 8. 评测方向

RAG 评测不只看回答是否通顺，还要看：

- 是否命中正确文档。
- 是否引用正确来源。
- 是否拒绝编造缺失信息。
- 是否识别高风险场景。
- 是否给出符合企业流程的建议。

典型测试问题：

```text
采购超过 5 万需要谁审批？
空压机 E07 报警且产线暂停，工单优先级是什么？
客户投诉尺寸偏差是否需要开 NCR？
临时焊接是否需要动火审批？
周报中什么时候不能标记为绿色？
```
