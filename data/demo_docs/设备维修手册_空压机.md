## 1. 目的

为保障公司压缩空气系统稳定运行，降低因空压机故障导致的产线停机、质量异常和安全风险，特制定本手册。

本手册主要用于规范以下事项：

1. 空压机日常点检与维护保养；
2. 常见故障码与异常现象识别；
3. 故障等级判定与工单优先级划分；
4. 维修处理步骤与安全注意事项；
5. 备件更换、验收与维修闭环；
6. 维修记录、异常复盘和审计追踪。

## 3. 角色与职责

### 3.1 生产操作员

生产操作员负责发现异常、记录现象并及时上报，不得擅自拆卸空压机、电控柜、压力管路或安全阀。

生产操作员应执行以下操作：

1. 每班检查末端气压是否在工艺要求范围内；
2. 发现报警、异响、异味、漏油、漏气或压力波动时，立即通知班组长；
3. 按要求填写《设备异常初报信息》；
4. 在设备部确认前，不得强行复位或重复启动故障设备。

### 3.2 班组长

班组长负责确认异常是否影响生产节拍、产品质量或人员安全，并决定是否升级通知设备部。

班组长应执行以下操作：

1. 判断异常是否导致产线停机、节拍下降或不良品增加；
2. 组织现场隔离，避免继续扩大影响；
3. 对一级故障进行现场初步确认；
4. 二级及以上故障必须发起维修工单。

### 3.3 设备工程师

设备工程师负责故障诊断、维修处理、备件申请、试机验收和维修记录归档。

设备工程师应执行以下操作：

1. 接收维修工单并确认故障等级；
2. 执行停机、断电、泄压、锁定挂牌等安全步骤；
3. 根据故障码和现场现象进行诊断；
4. 完成维修处理、试运行和恢复确认；
5. 记录原因、措施、备件、工时和后续建议。

### 3.4 设备主管

设备主管负责二级及以上故障审批、维修资源协调、外协维修确认和重复故障复盘。

以下情况必须由设备主管确认：

1. 故障导致单条产线停机超过 30 分钟；
2. 维修预计超过 2 小时；
3. 需要外协服务商到场；
4. 单次备件费用预计超过 3000 元；
5. 30 天内同一设备发生 2 次及以上同类故障。

### 3.5 安全部

安全部负责高风险维修作业的安全确认，包括带压系统、受限空间、动火、吊装、电气检修等场景。

以下情况必须通知安全部：

1. 储气罐、安全阀、压力管路存在异常；
2. 维修涉及动火、切割、焊接；
3. 存在喷油、冒烟、异味、电气烧蚀风险；
4. 设备异常可能造成人员伤害；
5. 需要临时旁路、临时接线或解除安全联锁。

## 4. 空压机系统基本运行要求

### 4.1 正常运行范围

| 项目 | 正常范围 | 预警范围 | 异常范围 |
|---|---:|---:|---:|
| 排气压力 | 0.65–0.80 MPa | 0.55–0.65 MPa 或 0.80–0.85 MPa | <0.55 MPa 或 >0.85 MPa |
| 排气温度 | 70–90℃ | 90–100℃ | >100℃ |
| 油位 | 油位镜 1/2–2/3 | 接近下限 | 低于下限 |
| 运行电流 | 额定电流 ±10% | 超出 ±10% | 超出 ±20% |
| 末端压力波动 | ≤0.05 MPa | 0.05–0.10 MPa | >0.10 MPa |

### 4.2 禁止操作

任何人员不得执行以下操作：

1. 设备报警后未经确认直接连续复位；
2. 运行状态下打开电控柜或拆卸防护罩；
3. 未泄压即拆卸管路、过滤器、阀件；
4. 临时短接压力、温度、电流、门禁等保护信号；
5. 使用非批准型号润滑油、滤芯或传感器；
6. 在没有安全确认的情况下带故障运行。

## 5. 点检与保养要求

### 5.1 每班点检

生产操作员和设备巡检人员每班应确认以下项目：

| 点检项目 | 正常状态 | 异常处理 |
|---|---|---|
| 操作面板 | 无报警、状态为运行或待机 | 记录报警代码并上报 |
| 排气压力 | 0.65–0.80 MPa | 检查是否漏气或负载异常 |
| 排气温度 | 70–90℃ | 超过 95℃通知设备部 |
| 声音 | 无明显尖叫、撞击、摩擦声 | 异响必须停机确认 |
| 油位 | 油位镜 1/2–2/3 | 低油位不得继续运行 |
| 漏油漏气 | 无明显泄漏 | 设置警示并报修 |
| 现场环境 | 通风良好、无杂物遮挡 | 清理周边杂物 |

### 5.2 每周维护

设备部每周执行以下维护：

1. 清洁空压机进风滤网；
2. 检查冷却风扇运行状态；
3. 检查排水阀、冷干机和过滤器状态；
4. 检查管路接头是否松动；
5. 检查控制柜散热情况；
6. 复核运行压力和末端压力波动。

### 5.3 每月维护

设备部每月执行以下维护：

1. 检查空气滤芯压差；
2. 检查油气分离器压差；
3. 校验压力传感器读数；
4. 检查安全阀铅封和有效期；
5. 检查电机端子和接地状态；
6. 输出《空压机月度运行状态记录》。

### 5.4 定期保养周期

| 保养项目 | 周期 | 责任人 |
|---|---:|---|
| 空气滤芯检查 | 每月 | 设备工程师 |
| 空气滤芯更换 | 2000 小时或压差超限 | 设备工程师 |
| 润滑油检查 | 每月 | 设备工程师 |
| 润滑油更换 | 4000 小时或油品异常 | 设备工程师 |
| 油过滤器更换 | 4000 小时 | 设备工程师 |
| 油气分离器更换 | 8000 小时或压差超限 | 设备工程师 |
| 安全阀校验 | 每年 | 设备部/外部机构 |
| 压力传感器校验 | 每半年 | 设备工程师/计量人员 |

## 6. 故障等级与工单优先级

### 6.1 故障等级定义

| 等级 | 定义 | 处理要求 |
|---|---|---|
| 一级故障 | 未影响生产节拍，无明显安全风险，可短时间观察处理 | 班组长记录，设备工程师当班处理 |
| 二级故障 | 影响单工位或局部设备运行，可能导致节拍下降或质量波动 | 必须发起维修工单，设备主管确认 |
| 三级故障 | 导致产线停机、存在安全风险、压力系统异常或重复故障 | 立即停机隔离，通知设备主管、生产经理和安全部 |
| 四级故障 | 发生冒烟、火情、人员伤害、储气罐异常、安全阀失效等重大风险 | 启动安全应急流程，现场封控，禁止擅自恢复 |

### 6.2 工单优先级

| 工单优先级 | 触发条件 | 响应时限 |
|---|---|---:|
| P1 紧急 | 产线停机、人员安全风险、压力系统失控 | 10 分钟内响应 |
| P2 高 | 产线降速、关键设备不可用、质量风险上升 | 30 分钟内响应 |
| P3 中 | 单台设备异常但有备用设备，可计划维修 | 4 小时内响应 |
| P4 低 | 点检缺陷、保养建议、非生产影响项 | 2 个工作日内处理 |

### 6.3 必须升级的情形

出现以下任一情形，应升级为 P1 或 P2 工单：

1. 空压机报警导致 A/B/C 任一产线停机；
2. 排气温度超过 105℃；
3. 储气罐压力异常或安全阀动作；
4. 设备出现烧焦味、冒烟、异常振动；
5. 末端气压不足导致夹具动作异常；
6. 关键质量检测设备因气压不足无法稳定工作；
7. 同一故障码 7 天内重复出现 2 次及以上。

## 7. 常见报警代码与处理建议

### 7.1 E01：排气温度过高

| 项目 | 内容 |
|---|---|
| 可能原因 | 环境通风不良、冷却器堵塞、润滑油不足、温度传感器异常、冷却风扇故障 |
| 风险 | 长时间运行可能导致机头损坏、润滑失效、电机过载 |
| 初步处理 | 停机冷却，检查通风、油位、冷却风扇和散热器 |
| 是否可复位 | 必须确认温度恢复正常后，由设备工程师复位 |
| 是否升级 | 超过 105℃或重复报警时升级为 P2；伴随冒烟或异味时升级为 P1 |

### 7.2 E02：排气压力过高

| 项目 | 内容 |
|---|---|
| 可能原因 | 压力传感器漂移、加载阀异常、管路堵塞、压力设定错误、卸载阀失效 |
| 风险 | 管路超压、储气罐安全阀动作、用气设备损坏 |
| 初步处理 | 停机确认压力表读数，检查压力设定和卸载状态 |
| 是否可复位 | 禁止未经确认直接复位 |
| 是否升级 | 压力超过 0.85 MPa 或安全阀动作时升级为 P1 |

### 7.3 E03：电机过载

| 项目 | 内容 |
|---|---|
| 可能原因 | 电机故障、轴承异常、供电电压异常、机头阻力过大、接触器异常 |
| 风险 | 电机烧毁、电气火灾、设备突然停机 |
| 初步处理 | 切断电源，检查电流记录、电机温升和电控柜状态 |
| 是否可复位 | 必须由设备工程师确认后复位 |
| 是否升级 | 出现烧焦味、跳闸或电控柜异常时升级为 P1，并通知安全部 |

### 7.4 E04：油位过低

| 项目 | 内容 |
|---|---|
| 可能原因 | 润滑油不足、漏油、油位传感器异常、保养后加油不足 |
| 风险 | 机头润滑不足、温度升高、机械损坏 |
| 初步处理 | 停机检查油位，确认是否漏油，按规定型号补油 |
| 是否可复位 | 补油并确认无泄漏后复位 |
| 是否升级 | 存在明显漏油或油位快速下降时升级为 P2 |

### 7.5 E05：空气滤芯压差过高

| 项目 | 内容 |
|---|---|
| 可能原因 | 空气滤芯堵塞、进风口遮挡、现场粉尘较多 |
| 风险 | 能耗上升、产气量下降、温度升高 |
| 初步处理 | 检查进风区域，清洁或更换空气滤芯 |
| 是否可复位 | 更换或清洁后可复位 |
| 是否升级 | 若导致压力不足或产线节拍下降，升级为 P2 |

### 7.6 E06：油气分离器压差过高

| 项目 | 内容 |
|---|---|
| 可能原因 | 油气分离器堵塞、润滑油劣化、保养周期超期 |
| 风险 | 能耗升高、排气含油量增加、后端过滤器污染 |
| 初步处理 | 检查运行小时数和压差记录，安排更换油气分离器 |
| 是否可复位 | 不得仅复位不更换 |
| 是否升级 | 若影响产品清洁度或检测设备稳定性，通知质量部评估 |

### 7.7 E07：压力传感器异常

| 项目 | 内容 |
|---|---|
| 可能原因 | 接线松动、传感器漂移、过滤器堵塞、控制模块异常、信号线受干扰 |
| 风险 | 压力判断失真，可能导致误加载、误卸载或超压运行 |
| 初步处理 | 停机确认机械压力表读数，检查传感器接线，校验压力传感器 |
| 是否可复位 | 仅在传感器读数与机械压力表一致后允许复位 |
| 是否升级 | 若生产线停机或末端压力不稳定，升级为 P1；若未停机但影响节拍，升级为 P2 |
| 备件建议 | 压力传感器、信号线、端子排、过滤器滤芯 |

### 7.8 E08：冷干机异常

| 项目 | 内容 |
|---|---|
| 可能原因 | 冷媒不足、冷凝器堵塞、排水阀堵塞、温控器异常 |
| 风险 | 压缩空气含水量升高，影响气动元件和产品质量 |
| 初步处理 | 检查冷干机运行状态、露点温度和自动排水阀 |
| 是否可复位 | 修复冷干机异常后复位 |
| 是否升级 | 若影响质量检测设备或气动夹具稳定性，通知质量部评估 |

## 8. 典型异常场景处理

### 8.1 空压机 E07 报警且 A 产线暂停

处理流程：

1. 生产操作员立即通知班组长，记录报警时间、设备编号和产线状态；
2. 班组长确认是否已导致 A 产线暂停；
3. 若产线已暂停，工单优先级设为 P1；
4. 设备工程师到场后执行停机、断电、泄压、锁定挂牌；
5. 使用机械压力表核对当前压力；
6. 检查压力传感器接线、信号线、端子排和控制模块；
7. 若传感器漂移，执行校验或更换；
8. 试运行 15 分钟，确认压力稳定后恢复生产；
9. 维修工单中记录故障码、原因、措施、备件和停机时长。

### 8.2 排气温度持续高于 100℃但未停机

处理流程：

1. 将工单优先级设为 P2；
2. 检查通风条件和周边散热空间；
3. 检查油位、润滑油状态和冷却风扇；
4. 清理散热器表面灰尘；
5. 如温度仍超过 100℃，安排停机检查；
6. 若温度超过 105℃或伴随异味，升级为 P1。

### 8.3 末端气压不足导致气动夹具动作变慢

处理流程：

1. 班组长确认影响工位和影响范围；
2. 设备工程师检查空压机排气压力、冷干机、过滤器和末端管路；
3. 若主机压力正常但末端压力不足，优先检查管路漏气和过滤器堵塞；
4. 若影响产品定位或检测结果，应通知质量部评估已生产批次；
5. 维修完成后，由生产部确认夹具动作恢复正常。

### 8.4 空压机漏油

处理流程：

1. 立即在漏油区域设置警示标识；
2. 若漏油接近电气柜、高温部件或人员通道，升级为 P1；
3. 停机检查油管、接头、油滤、油分和密封件；
4. 清理现场油污，避免滑倒风险；
5. 更换密封件或紧固接头后试运行；
6. 记录漏油位置、处理措施和清理结果。

## 9. 维修作业安全要求

### 9.1 停机确认

执行维修前必须完成以下步骤：

1. 通知生产班组长；
2. 停止设备运行；
3. 切断主电源；
4. 执行锁定挂牌；
5. 释放系统残余压力；
6. 确认压力表归零；
7. 等待高温部件冷却；
8. 设置维修隔离标识。

### 9.2 带压系统作业要求

任何人员不得在系统带压状态下拆卸管路、阀门、过滤器、压力传感器或安全阀。

涉及储气罐、安全阀、主管路改造的作业必须经设备主管和安全部确认。

### 9.3 电气检修要求

涉及电机、电控柜、变频器、接触器、控制模块和传感器线路的维修，必须由具备电气维修资格的设备工程师执行。

发现以下情况时必须通知安全部：

1. 电控柜有烧焦味；
2. 线缆绝缘破损；
3. 接线端子发黑；
4. 设备外壳带电；
5. 频繁跳闸或漏电保护动作。

## 11. 维修验收与恢复生产

### 11.1 试运行要求

维修完成后，设备工程师必须执行试运行确认：

1. 空载运行不少于 5 分钟；
2. 加载运行不少于 15 分钟；
3. 排气压力稳定在 0.65–0.80 MPa；
4. 排气温度稳定低于 95℃；
5. 无异常振动、异响、漏油、漏气；
6. 控制面板无报警；
7. 末端用气点压力恢复正常。

### 11.2 恢复生产确认

设备恢复后，必须由生产班组长确认：

1. 相关工位恢复运行；
2. 气动夹具动作正常；
3. 检测设备供气正常；
4. 生产节拍恢复；
5. 维修隔离标识已撤除。

涉及质量风险的异常，还必须由质量工程师确认是否需要追溯已生产批次。

## 13. 重复故障复盘

### 13.1 复盘触发条件

出现以下任一情况时，设备主管必须组织复盘：

1. 同一设备 30 天内发生 2 次及以上同类故障；
2. 单次停机超过 2 小时；
3. 故障导致批量质量风险；
4. 维修后 24 小时内再次报警；
5. 设备故障导致安全事件或险情。

### 13.2 复盘内容

复盘应至少包含：

1. 故障发生时间线；
2. 直接原因和根本原因；
3. 点检保养是否执行到位；
4. 备件质量和型号是否符合要求；
5. 是否存在操作不当或环境问题；
6. 是否需要调整保养周期；
7. 是否需要培训操作员或维修人员；
8. 是否需要更新本手册。

## 15. 常见问答

### 15.1 空压机报警后能不能先复位再观察？

不能。报警后必须先确认报警原因。涉及温度、压力、电机、电气和安全阀的报警，未经设备工程师确认不得复位。

### 15.2 空压机 E07 报警但压力看起来正常，是否可以继续运行？

不建议继续运行。E07 代表压力传感器异常，可能导致控制系统误判。必须用机械压力表核对，并检查传感器接线和信号。

### 15.3 空压机压力不足但主机没有报警，应该查哪里？

优先检查末端管路漏气、过滤器堵塞、冷干机排水异常、用气负载突增和压力表是否失准。

### 15.4 生产赶工时能否临时解除保护运行？

禁止。任何解除保护、短接信号、带故障运行的行为都必须停止，并上报设备主管和安全部。

### 15.5 维修完成后谁确认可以恢复生产？

设备工程师确认设备状态，生产班组长确认产线恢复。若存在质量风险，还需质量工程师确认。
