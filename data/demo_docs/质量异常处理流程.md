# 质量异常处理流程

**文件编号：HDJG-ZL-LC-QA-2026-01**  
**适用部门：质量部、生产部、设备部、采购部、仓储部、研发工艺部**  
**适用范围：来料、制程、成品、客户反馈及供应商相关质量异常**  
**版本：V1.0**  
**生效日期：2026-01-01**  
**编制部门：质量部**  
**审批部门：质量管理委员会**  

> 说明：本文档用于规范华东精工制造有限公司质量异常的发现、隔离、判定、处置、纠正预防、复盘和归档流程。所有质量异常必须以事实、数据、批次和证据为依据，不得以经验判断替代记录和审批。

---

## 1. 目的

为确保质量异常能够被及时发现、准确分级、有效隔离和闭环处理，防止不合格品流入下一工序、仓库或客户现场，特制定本流程。

本流程主要解决以下问题：

1. 异常发现后由谁记录、谁判断、谁升级；
2. 何种情况需要开具 NCR；
3. 何种情况需要停线、隔离、返工、报废或让步接收；
4. 如何追溯受影响批次和责任环节；
5. 如何形成纠正预防措施；
6. 如何保留审计证据和复盘记录。

---

## 2. 适用范围

本流程适用于公司范围内以下质量异常：

1. 来料检验发现的尺寸、外观、材质、性能、包装、标签异常；
2. 制程检验发现的尺寸超差、装配不良、工艺参数异常；
3. 设备异常引发的产品质量波动；
4. 成品检验发现的不合格；
5. 客户退货、客户投诉、客户现场质量反馈；
6. 供应商批量不良或重复不良；
7. 仓储、搬运、包装、标识错误导致的质量风险；
8. 检测设备、量具或检验方法异常导致的测量风险。

---

## 3. 术语定义

| 术语 | 定义 |
|---|---|
| 质量异常 | 产品、过程、物料、设备或检测结果偏离规定要求，可能影响质量、交付或客户满意度的事件 |
| 不合格品 | 经检验确认不满足图纸、标准、工艺文件或客户要求的产品 |
| NCR | Non-Conformance Report，不符合报告，用于记录和管理质量异常 |
| MRB | Material Review Board，材料评审小组，用于评审重大或复杂质量处置 |
| 隔离 | 将疑似或确认不合格物料/产品与合格品分开，并进行状态标识 |
| 让步接收 | 在不影响安全、法规和客户关键要求的前提下，经审批后接受偏离要求的产品 |
| 返工 | 按规定方法使不合格品重新满足要求 |
| 返修 | 通过修复使产品可使用，但不一定完全恢复到原设计状态 |
| 报废 | 产品无法满足使用要求或修复成本不合理，经审批后作废处理 |
| 纠正措施 | 消除已发生不合格原因的措施 |
| 预防措施 | 防止潜在不合格发生的措施 |

## 4. 角色与职责

### 4.1 生产操作员

生产操作员是制程异常的第一发现人，应做到发现即停、发现即报、发现即记。

职责包括：

1. 发现异常后立即暂停继续生产或流转可疑产品；
2. 通知班组长和现场质量检验员；
3. 保留异常样件、设备状态、参数记录和现场照片；
4. 不得私自返工、混放、替换、报废或放行异常品。

### 4.2 班组长

班组长负责现场初步确认和临时隔离。

职责包括：

1. 确认异常发生工位、时间、批次和数量；
2. 组织隔离在制品、半成品和疑似受影响产品；
3. 判断是否影响生产节拍或交付；
4. 轻微异常可记录处理；一般及以上异常必须通知质量工程师；
5. 重大异常必须立即通知生产主管和质量主管。

### 4.3 质量检验员

质量检验员负责现场检验、判定证据收集和异常记录。

职责包括：

1. 复核异常样品；
2. 记录检验数据、抽样数量和不良数量；
3. 对异常品进行状态标识；
4. 建议是否开具 NCR；
5. 将异常信息提交质量工程师。

### 4.4 质量工程师

质量工程师负责 NCR 开具、分级判定、原因分析组织、处置方案和闭环确认。

职责包括：

1. 判断异常等级；
2. 开具 NCR 或质量异常记录；
3. 组织生产、设备、采购、供应商或工艺人员分析原因；
4. 明确处置方式；
5. 跟踪纠正预防措施；
6. 验证措施有效性并关闭问题。

### 4.5 生产主管

生产主管负责生产资源协调、停线决策参与、返工安排和交付影响评估。

职责包括：

1. 协调隔离区域和返工人员；
2. 评估停线、降速或切换工单的必要性；
3. 配合追溯受影响批次；
4. 执行经审批的返工或筛选方案。

### 4.6 设备工程师

当异常可能与设备状态、工装夹具、气压、电气、传感器、检测设备或维护保养有关时，设备工程师必须参与原因分析。

职责包括：

1. 检查设备运行参数；
2. 核实设备维修、点检和报警记录；
3. 判断设备异常是否可能导致质量波动；
4. 提供维修记录和恢复确认；
5. 对设备相关原因制定纠正预防措施。

### 4.7 采购部

当异常涉及供应商、外购物料、外协加工或供应商变更时，采购部必须参与处理。

职责包括：

1. 通知供应商提交原因分析和改善报告；
2. 协调退货、补货、索赔和替换物料；
3. 对供应商重复异常提出整改要求；
4. 配合质量部调整供应商状态。

### 4.8 MRB 小组

MRB 小组适用于重大异常、客户相关异常、让步接收、批量返工、报废金额较大或责任归属复杂的场景。

MRB 通常由质量部、生产部、工艺部、采购部、设备部、财务部及必要时的销售/客户代表组成。

## 5. 质量异常分级

### 5.1 分级原则

质量异常分为四级：轻微异常、一般异常、重大异常、客户/安全重大异常。

| 等级 | 定义 | 处理要求 |
|---|---|---|
| 轻微异常 | 单件或少量偏差，不影响功能、安全、装配和客户要求，可现场纠正 | 班组长和检验员记录，质量工程师抽查 |
| 一般异常 | 影响局部批次、需要返工/筛选/工艺调整，尚未流出本工序 | 必须开具 NCR，由质量工程师主导处理 |
| 重大异常 | 批量不良、跨工序流转、影响交付、需要停线或涉及供应商批量问题 | 质量主管牵头，必要时启动 MRB |
| 客户/安全重大异常 | 可能流入客户、影响安全法规、关键特性失控、客户投诉或退货 | 立即升级质量总监和生产运营中心，启动专项处理 |

### 5.2 必须升级为重大异常的情形

出现以下任一情况，应按重大异常处理：

1. 同一批次不良率超过 3%；
2. 同一缺陷在 24 小时内重复出现 3 次及以上；
3. 异常涉及关键尺寸、关键性能、气密性、强度或安全特性；
4. 异常产品已经流入下一工序或成品库；
5. 异常可能影响客户交付；
6. 设备故障导致连续生产质量波动；
7. 供应商来料批量不良；
8. 检测设备失准导致历史检验结果需要复核。

### 5.3 必须启动客户/安全重大异常的情形

出现以下任一情况，应按客户/安全重大异常处理：

1. 不合格品已发往客户；
2. 客户投诉、客户退货或客户现场发现缺陷；
3. 涉及安全法规、客户特殊特性或强制认证要求；
4. 存在产品失效、装配失效或人身安全风险；
5. 可能需要向客户提交 8D 报告；
6. 同一客户同类问题 90 天内重复发生。

## 6. 异常处理总流程

质量异常处理按以下流程执行：

```text
发现异常
↓
现场暂停与初步隔离
↓
记录异常信息
↓
质量检验员复核
↓
质量工程师分级
↓
是否开具 NCR
↓
原因分析与影响范围确认
↓
确定处置方案
↓
执行返工/筛选/退货/报废/让步接收/放行
↓
纠正预防措施
↓
效果验证
↓
关闭归档
```

## 7. 现场发现与初步隔离

### 7.1 发现异常后的第一动作

任何人员发现质量异常后，应立即执行“三不原则”：

1. 不接收不合格品；
2. 不制造不合格品；
3. 不流出不合格品。

现场人员必须执行：

1. 暂停可疑产品继续流转；
2. 保留异常样件；
3. 通知班组长和质量检验员；
4. 标识异常区域；
5. 记录发生时间、工位、批次和数量。

### 7.2 隔离要求

所有疑似异常品必须进入隔离状态，隔离方式包括：

1. 放入红色不合格品箱；
2. 粘贴“不合格/待判定”标签；
3. 在系统中冻结批次；
4. 单独划定隔离区域；
5. 对已流转产品进行追溯封存。

隔离标签应包含：

```text
产品名称：
物料编码：
批次号：
数量：
发现工序：
发现时间：
异常描述：
隔离人：
状态：待判定/返工/报废/让步/退货
```

## 8. 异常记录要求

### 8.1 初报信息

异常初报必须包含以下内容：

| 字段 | 要求 |
|---|---|
| 异常编号 | 系统自动生成或由质量部编号 |
| 发现时间 | 精确到分钟 |
| 发现部门 | 生产部/质量部/仓储部等 |
| 发现工位 | 具体产线和工序 |
| 产品名称 | 与工单或物料主数据一致 |
| 产品批次 | 必须可追溯 |
| 异常描述 | 用事实描述，不得只写“不良” |
| 检验数据 | 尺寸、压力、扭矩、外观缺陷数量等 |
| 影响数量 | 已确认不良、疑似数量、已流转数量 |
| 初步措施 | 暂停、隔离、标识、通知等 |
| 附件证据 | 照片、检验记录、设备参数、报警记录 |

### 8.2 描述规范

异常描述应避免模糊表达。

不推荐：

```text
产品有问题，尺寸不太对。
```

推荐：

```text
A3 产线 OP40 工序，批次 B20260312-01，抽检 20 件中 3 件孔径超上限，实测 10.18–10.21 mm，图纸要求 10.00±0.05 mm。
```

## 9. NCR 开具规则

### 9.1 必须开具 NCR 的情形

出现以下任一情况必须开具 NCR：

1. 一般异常及以上等级；
2. 需要返工、返修、筛选、报废或让步接收；
3. 不良原因暂不明确；
4. 涉及供应商来料异常；
5. 涉及设备故障、工装异常或检测设备异常；
6. 涉及跨部门处理；
7. 异常产品已经流入下一工序、仓库或客户；
8. 同类轻微异常 7 天内重复发生 2 次及以上。

### 9.2 可不单独开具 NCR 的情形

以下情形可仅做质量异常记录，但应由质量工程师抽查：

1. 单件外观轻微缺陷，已现场剔除且未流转；
2. 操作员自检发现并立即纠正的非关键问题；
3. 不影响功能、装配、客户要求且无重复趋势的小偏差；
4. 已纳入日常过程控制记录的轻微波动。

### 9.3 NCR 编号规则

NCR 编号格式：

```text
NCR-年份-月份-流水号
示例：NCR-2026-03-0012
```

供应商来料异常可增加供应商标识：

```text
NCR-SQ-2026-03-0008
```

客户投诉相关异常可增加客户标识：

```text
NCR-CQ-2026-03-0003
```

## 10. 影响范围确认

### 10.1 追溯范围

质量工程师应根据异常类型确定追溯范围：

| 异常类型 | 最小追溯范围 |
|---|---|
| 单件外观异常 | 同工位同班次产品 |
| 尺寸超差 | 同设备、同刀具/夹具、同批次产品 |
| 设备参数异常 | 设备报警前后至少 2 小时产品 |
| 来料异常 | 同供应商、同批次、同到货单产品 |
| 检测设备失准 | 上次校准合格后至本次发现期间检验过的产品 |
| 客户投诉 | 同客户、同型号、同生产批次及相邻批次 |

### 10.2 已流转产品处理

若异常产品可能已流入下一工序、成品库或客户现场，应立即执行：

1. 冻结系统库存；
2. 通知仓储部暂停发货；
3. 通知生产部暂停同批次继续加工；
4. 通知质量主管评估是否扩大追溯；
5. 如已发往客户，由质量主管和销售/客户接口人员共同处理。

## 11. 原因分析

### 11.1 原因分类

质量异常原因可分为以下类别：

| 类别 | 示例 |
|---|---|
| 人员 | 操作方法错误、漏检、未按作业指导书执行 |
| 设备 | 设备磨损、夹具松动、空压机压力波动、传感器异常 |
| 物料 | 来料尺寸不良、材质异常、供应商批次波动 |
| 方法 | 工艺参数错误、检验方法不一致、作业指导书不清晰 |
| 环境 | 温湿度、粉尘、照明、气源、水分影响 |
| 测量 | 量具失准、检测设备异常、测量程序错误 |

### 11.2 分析工具

质量工程师可根据问题复杂度选择以下工具：

1. 5 Why 分析；
2. 鱼骨图；
3. Pareto 分析；
4. 过程参数趋势分析；
5. 设备报警与维修记录比对；
6. 批次追溯；
7. 供应商 8D 报告；
8. 测量系统分析。

### 11.3 设备相关异常分析

当异常可能与设备相关时，必须检查：

1. 最近 72 小时设备报警记录；
2. 最近一次维修和保养记录；
3. 工装夹具状态；
4. 设备关键参数趋势；
5. 空压机供气压力、冷干机和过滤器状态；
6. 检测设备校准状态；
7. 是否存在临时调整、换型或异常停机。

例如，若气动夹具夹紧力不足导致尺寸波动，应同时追溯空压机压力、末端压力、夹具气缸状态和设备维修记录。

## 12. 处置方式

质量异常处置方式包括：放行、筛选、返工、返修、退货、报废、让步接收和暂停生产。

### 12.1 放行

只有在复核确认产品满足要求，或异常不成立时，才可放行。

放行必须由质量工程师确认，不得由生产人员单独决定。

### 12.2 筛选

当异常可能影响部分产品但无法直接区分时，应执行筛选。

筛选方案必须明确：

1. 筛选范围；
2. 检验项目；
3. 检验工具；
4. 合格判定标准；
5. 人员安排；
6. 筛选记录；
7. 二次抽查比例。

### 12.3 返工

返工必须有明确作业方法和检验标准。

返工后必须重新检验，不得直接流转。

### 12.4 返修

返修适用于产品可恢复使用但可能无法完全恢复原设计状态的情况。涉及客户要求、关键特性或安全性能时，必须经质量主管审批。

### 12.5 退货

供应商来料异常可以退货。采购部负责与供应商沟通，质量部负责提供异常证据和判定依据。

### 12.6 报废

报废适用于无法修复、修复成本过高或存在安全风险的产品。

报废审批要求：

| 报废金额 | 审批要求 |
|---:|---|
| ≤ 1000 元 | 质量工程师 + 生产主管 |
| 1000–10000 元 | 质量主管 + 生产主管 + 财务确认 |
| > 10000 元 | MRB 评审 + 质量总监审批 |

### 12.7 让步接收

让步接收必须谨慎使用，且不得用于以下场景：

1. 安全特性不符合；
2. 法规或认证要求不符合；
3. 客户明确禁止让步；
4. 关键尺寸或关键性能失控；
5. 无法证明不影响功能和寿命；
6. 客户投诉相关问题未经客户同意。

让步接收审批要求：

| 场景 | 审批要求 |
|---|---|
| 内部非关键偏差 | 质量主管 + 工艺工程师 |
| 影响装配但可控 | MRB 评审 |
| 涉及客户要求 | 客户书面确认 + 质量总监审批 |

## 13. 停线与恢复生产

### 13.1 停线触发条件

出现以下任一情形，生产主管和质量主管应立即评估停线：

1. 不良率超过 5% 且原因未明；
2. 关键特性连续 2 次超差；
3. 设备异常导致产品尺寸或性能波动；
4. 检测设备失准，无法确认产品合格；
5. 异常可能继续扩大；
6. 存在安全风险或客户重大风险。

### 13.2 临时恢复生产条件

恢复生产前必须满足：

1. 异常原因已初步确认；
2. 可疑产品已隔离；
3. 临时控制措施已执行；
4. 首件或过程验证合格；
5. 质量工程师确认可恢复；
6. 生产主管确认生产条件具备。

### 13.3 正式恢复生产条件

正式恢复生产应满足：

1. 根本原因已明确；
2. 纠正措施已实施；
3. 连续生产验证合格；
4. 质量记录完整；
5. 必要时完成客户或内部审批；
6. NCR 状态更新为“待验证”或“已关闭”。

---

## 14. 纠正预防措施

### 14.1 措施制定

纠正预防措施必须对应原因，不得只写“加强培训”“加强检验”等笼统措施。

不推荐：

```text
加强员工质量意识，后续注意。
```

推荐：

```text
将 OP40 工序夹具定位销点检频次由每周一次调整为每班一次；新增首件孔径复测要求；设备部于 3 月 20 日前更换磨损定位销。
```

### 14.2 措施责任

每项措施必须明确：

1. 责任部门；
2. 责任人；
3. 完成期限；
4. 验证方法；
5. 预期效果；
6. 关闭条件。

### 14.3 效果验证

质量工程师应在措施实施后进行效果验证。

验证方式包括：

1. 连续 3 批产品合格；
2. 连续 5 个工作日未再发生同类异常；
3. 过程能力或不良率恢复到目标范围；
4. 设备参数稳定；
5. 供应商提交并通过改善报告；
6. 客户未再反馈同类问题。

---

## 15. 供应商质量异常

### 15.1 来料异常处理

来料检验发现异常后，应执行：

1. 暂停入库；
2. 隔离异常批次；
3. 记录供应商、批次、到货单号和异常数量；
4. 开具 NCR-SQ；
5. 通知采购部和供应商；
6. 评估库存和生产影响；
7. 确定退货、换货、筛选、让步或供应商现场处理。

### 15.2 供应商整改要求

以下情况必须要求供应商提交整改报告：

1. 批量来料不良；
2. 同一供应商 30 天内发生 2 次以上异常；
3. 异常影响生产交付；
4. 异常涉及关键物料；
5. 异常导致客户风险。

供应商整改报告至少应包含：

1. 问题描述；
2. 遏制措施；
3. 根本原因分析；
4. 永久纠正措施；
5. 效果验证；
6. 防止再发措施；
7. 责任人和完成日期。

### 15.3 供应商状态调整

质量部可根据异常严重程度建议调整供应商状态：

| 状态 | 触发条件 |
|---|---|
| 正常 | 质量表现稳定 |
| 观察 | 一般异常重复发生 |
| 限制 | 批量异常或整改无效 |
| 暂停 | 重大异常、客户风险或拒不整改 |
| 取消 | 多次重大异常且无法改善 |

采购部应根据质量部建议执行供应商商务处理。

---

## 16. 客户质量异常

### 16.1 客户投诉响应

收到客户投诉后，质量部应在 2 小时内完成内部登记，并在 1 个工作日内组织初步分析。

客户投诉必须执行：

1. 登记客户投诉编号；
2. 确认客户、产品、批次、数量和问题描述；
3. 立即冻结相关库存；
4. 追溯同批次和相邻批次；
5. 组织临时遏制措施；
6. 必要时提交 8D 报告；
7. 跟踪客户确认结果。

### 16.2 客户退货处理

客户退货到厂后，质量部应组织复检，并确认：

1. 是否与客户描述一致；
2. 是否属于公司责任；
3. 是否涉及运输、包装或客户使用条件；
4. 是否需要扩大召回或替换；
5. 是否需要供应商或工艺部门参与。

---

## 17. 与设备维修流程的衔接

当质量异常可能由设备引起时，应同时触发设备检查或维修工单。

以下情况必须关联设备维修记录：

1. 空压机压力波动影响气动夹具动作；
2. 设备报警后产品尺寸波动；
3. 检测设备校准异常；
4. 工装夹具磨损或定位异常；
5. 设备维修后 24 小时内出现质量异常；
6. 产线停机恢复后出现批量不良。

质量 NCR 中必须记录相关设备编号、工单编号、报警代码和维修结论。

示例：

```text
质量异常编号：NCR-2026-03-0015
关联设备工单：WO-AC-2026-0017
设备编号：AC-A01
设备异常：E07 压力传感器异常
质量影响：A 产线气动夹具夹紧力波动，导致 3 件孔位尺寸超差
处置：隔离报警前后 2 小时产品，执行全检，设备修复后重新首件确认
```

## 18. 审批权限

### 18.1 NCR 关闭审批

| 异常等级 | 关闭审批 |
|---|---|
| 轻微异常 | 质量检验员记录，质量工程师抽查 |
| 一般异常 | 质量工程师关闭 |
| 重大异常 | 质量主管审批关闭 |
| 客户/安全重大异常 | 质量总监审批关闭 |

### 18.2 处置审批

| 处置方式 | 审批要求 |
|---|---|
| 放行 | 质量工程师确认 |
| 筛选 | 质量工程师 + 生产主管 |
| 返工 | 质量工程师 + 生产主管 |
| 返修 | 质量主管审批 |
| 报废 | 按金额审批 |
| 让步接收 | 质量主管/MRB/客户确认 |
| 停线 | 生产主管 + 质量主管 |
| 恢复生产 | 生产主管 + 质量工程师，重大异常需质量主管确认 |

## 20. 常见场景处理

### 20.1 抽检发现 20 件中 1 件外观轻微划伤

如果不影响功能、装配和客户外观要求，可按轻微异常处理。班组长和检验员记录，隔离该件产品，质量工程师抽查确认。

### 20.2 同一工位连续发现 3 件尺寸超差

应升级为重大异常。班组长暂停该工位流转，质量工程师开具 NCR，生产主管和设备工程师参与分析，追溯同设备、同夹具、同批次产品。

### 20.3 空压机压力波动后发现产品孔位偏差

应同时触发质量异常流程和设备维修流程。质量部隔离异常时间前后至少 2 小时产品，设备部检查空压机、末端压力、夹具气缸和相关维修记录。

### 20.4 供应商来料标签错误但物料本身合格

仍应开具 NCR-SQ 或供应商异常记录。若标签错误可能导致错用，应隔离并要求供应商整改。是否让步接收由质量工程师和仓储部确认，必要时采购部通知供应商。

### 20.5 客户反馈装配异响

应按客户质量异常处理。质量部登记客户投诉，冻结相关库存，追溯同批次和相邻批次，组织 8D 分析，并在客户要求时间内反馈临时遏制措施。

## 23. 审计与违规处理

### 23.1 审计重点

质量部和内审人员可对以下事项进行抽查：

1. 是否及时隔离异常品；
2. 是否存在未开 NCR 的一般及以上异常；
3. 是否存在未经审批放行；
4. 是否存在返工后未复检；
5. 是否存在报废、让步接收审批缺失；
6. 是否存在异常记录与实物状态不一致；
7. 是否存在客户投诉处理超期；
8. 是否存在供应商整改未关闭。

### 23.2 禁止行为

以下行为属于严重违规：

1. 隐瞒质量异常；
2. 私自放行不合格品；
3. 擅自返工、报废或混放异常品；
4. 修改、删除或伪造检验记录；
5. 未经审批让步接收；
6. 明知设备异常仍继续生产且不隔离产品；
7. 客户投诉未登记或延迟上报。
