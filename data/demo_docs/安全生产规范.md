# 华东精工制造有限公司安全生产规范

**文件编号：** HDJG-EHS-005  
**版本号：** V1.0  
**生效日期：** 2026-01-01  
**归口部门：** 安全环保部  
**适用范围：** 华东精工制造有限公司总部、生产车间、仓储区域、设备间、实验室及外协施工现场  
**密级：** 内部公开  

---

## 1. 目的

为规范公司生产、维修、仓储、搬运、试验、外协施工及办公支持活动中的安全管理要求，预防人身伤害、设备损坏、火灾、环境污染和生产中断事故，保障员工生命安全与公司财产安全，特制定本规范。

本规范用于明确各部门在安全生产中的责任、作业前确认要求、个人防护要求、设备安全、危险作业审批、隐患排查、事故报告与整改闭环等基本规则。所有员工、外协人员、临时访客在进入公司生产及仓储区域前，均应遵守本规范。

---

## 2. 适用范围

### 2.1 适用人员

本规范适用于以下人员：

1. 公司正式员工、试用期员工、实习人员；
2. 外协维修、安装调试、物流装卸、保洁、保安、施工单位人员；
3. 客户、供应商、审核机构、政府监管人员等外来访客；
4. 其他经公司批准进入生产、仓储、设备或试验区域的人员。

### 2.2 适用区域

本规范适用于以下区域：

1. 机加工车间、装配车间、检测室、返修区、试制区；
2. 空压机房、配电室、泵房、冷却水系统、设备维修间；
3. 原材料仓库、成品仓库、化学品暂存柜、危废暂存点；
4. 叉车通道、装卸平台、车辆等待区；
5. 临时施工区域、设备改造区域、试运行区域；
6. 其他存在机械、电气、火灾、坠落、化学、噪声或搬运风险的场所。

### 2.3 不适用事项

以下事项按专项制度执行，但不得低于本规范要求：

1. 特种设备法定检验和操作证管理；
2. 危险化学品采购、储存和处置；
3. 职业健康体检和职业病危害因素检测；
4. 建设工程、消防工程、环保工程等依法需专项审批的项目；
5. 重大事故应急预案、消防专项预案及政府监管事项。

## 3. 基本原则

### 3.1 安全优先原则

任何生产计划、交付节点、成本控制目标均不得凌驾于安全要求之上。发现存在直接人身伤害风险、火灾风险、触电风险、设备失控风险或重大质量安全风险时，现场人员有权立即停止相关作业，并向班组长、部门主管或安全环保部报告。

### 3.2 谁主管谁负责原则

各部门负责人是本部门安全管理第一责任人。生产部、设备部、质量部、仓储物流部、采购部、行政部等部门应对本部门人员、区域、设备和外协活动承担日常安全管理责任。

### 3.3 作业前确认原则

所有生产、维修、调试、吊装、动火、临时用电、高处作业、受限空间作业和叉车装卸活动，在开始前必须完成作业条件确认。未确认人员、设备、工具、环境、能源隔离和防护措施的，不得开始作业。

### 3.4 变更受控原则

设备参数、工艺路线、作业方法、物料替代、场地布局、人员配置、供应商施工方式发生变化时，应评估是否引入新的安全风险。未经评估和批准，不得擅自绕过联锁、防护罩、报警器、急停装置或安全门。

### 3.5 记录可追溯原则

安全培训、隐患排查、危险作业审批、事故报告、整改验证、外协入场教育、设备点检等记录应真实、完整、可追溯。禁止事后补签、代签、伪造检查记录或隐瞒安全事件。

## 4. 组织职责

### 4.1 总经理

1. 对公司安全生产工作承担最终管理责任；
2. 批准公司年度安全目标、重大安全投入和重大隐患整改计划；
3. 组织或授权组织重大事故调查和责任处理；
4. 对重大停产、重大危险作业和重大外协施工事项进行最终决策。

### 4.2 安全环保部

1. 制定、修订并解释公司安全生产制度；
2. 组织安全培训、专项检查、隐患排查和事故调查；
3. 监督危险作业审批、外协施工安全管理和消防管理；
4. 对重大隐患有权要求责任部门立即停工或整改；
5. 维护公司安全风险台账、隐患整改台账和事故事件台账。

### 4.3 生产部

1. 负责生产现场人员、工位、设备、物料和作业过程的日常安全管理；
2. 组织班组安全交底、班前会和岗位风险提示；
3. 确保员工按规定佩戴劳动防护用品并按标准作业；
4. 对违章操作、冒险作业和未授权作业进行制止；
5. 配合安全环保部完成事故调查和整改闭环。

### 4.4 设备部

1. 负责生产设备、公用工程、空压机、配电系统、特种设备和维修作业安全；
2. 制定设备点检、保养、维修和能源隔离要求；
3. 对设备安全防护、急停、联锁、报警、接地等装置进行检查；
4. 维修作业前确认断电、泄压、挂牌上锁等措施；
5. 对设备改造、临时接线、外协安装调试进行安全确认。

### 4.5 仓储物流部

1. 负责仓库、装卸平台、叉车通道、货架、堆垛和搬运活动安全；
2. 确保叉车、电动搬运车和吊具由授权人员使用；
3. 保持消防通道、安全出口、配电箱前方区域和应急物资通道畅通；
4. 负责物料堆放稳定性、限高管理和重物搬运风险提示；
5. 对装卸外来车辆和物流人员进行现场安全提醒。

### 4.6 质量部

1. 负责检测室、试验区、量具间、样件区和不合格品隔离区安全；
2. 在处理质量异常、返工、返修、挑选、报废时识别安全风险；
3. 对涉及产品安全、客户安全或批量返工的异常事项及时升级；
4. 配合生产部和设备部确认质量异常处理过程中的安全措施。

### 4.7 各级主管和班组长

1. 对本班组人员安全行为进行日常管理；
2. 开展班前安全提醒和作业前确认；
3. 对新员工、转岗员工、临时支援人员进行岗位风险说明；
4. 发现隐患或违章行为应立即制止并上报；
5. 对轻微事件、未遂事件和险肇事件及时记录。

### 4.8 员工个人

1. 遵守岗位安全操作规程；
2. 正确佩戴和使用劳动防护用品；
3. 不违章作业、不冒险作业、不擅自进入无关区域；
4. 发现异常声响、异味、烟雾、漏油、漏气、报警、过热、松动等情况，应立即报告；
5. 有权拒绝未进行安全交底、无防护措施或明显存在危险的作业安排。

## 5. 安全风险分级

为便于流程 Agent 识别风险等级并触发相应动作，公司将安全风险分为四级。

### 5.1 一级风险：一般风险

一般风险是指可能造成轻微伤害、轻微设备损伤或短时间现场混乱，但不直接导致停产、火灾、触电或重大伤害的风险。

常见场景包括：

1. 通道轻微堵塞但仍可通行；
2. 地面积水、油污面积较小；
3. 劳保用品佩戴不规范但未进入高风险作业；
4. 普通工具摆放不整齐；
5. 班组点检记录漏填一项但设备运行正常。

处理要求：班组长应在当班内组织整改，并在班组安全记录中登记。

### 5.2 二级风险：较大风险

较大风险是指可能造成员工受伤、设备故障扩大、质量异常扩大或局部生产中断的风险。

常见场景包括：

1. 设备防护罩松动、缺失或被临时移开；
2. 空压机、液压站、配电柜出现异常报警但设备尚未停机；
3. 叉车通道被物料占用影响车辆避让；
4. 化学品标签缺失或容器未盖严；
5. 维修作业未完整填写工单或未明确能源隔离责任人；
6. 员工在非授权区域进行临时作业。

处理要求：责任部门主管应在 4 小时内确认整改措施；必要时通知安全环保部或设备部现场确认。

### 5.3 三级风险：重大风险

重大风险是指可能造成严重人身伤害、火灾、触电、设备重大损坏、生产线停机或客户交付重大影响的风险。

常见场景包括：

1. 配电柜冒烟、异味、异常发热或有打火声；
2. 设备急停、联锁、安全门失效；
3. 空压机高温、高压、严重漏油、严重漏气并影响生产；
4. 叉车与人员发生碰撞或险些碰撞；
5. 动火、高处、吊装、临时用电作业未经审批已经开始；
6. 质量异常处理需要返修但返修过程存在夹伤、割伤、飞溅或误启动风险；
7. 消防通道被堵塞且影响人员疏散或应急车辆通行。

处理要求：立即暂停相关作业，由责任部门负责人、安全环保部和相关专业部门联合确认。未经确认不得恢复作业。

### 5.4 四级风险：紧急风险

紧急风险是指已经发生或极可能立即发生人身伤害、火灾、爆炸、触电、中毒、设备失控、重大泄漏或大范围停产的风险。

常见场景包括：

1. 明火、浓烟、爆燃、火灾报警；
2. 人员受伤、昏迷、触电、被困或疑似中毒；
3. 危险化学品大量泄漏；
4. 受限空间内人员失联或呼救；
5. 设备高速旋转部件失控、飞出或严重破裂；
6. 压力容器、管路或空压系统存在爆裂风险；
7. 现场人员无法自行控制的重大安全事件。

处理要求：立即停止作业、疏散人员、启动应急处置，拨打内部应急电话，并由安全环保部和公司应急负责人统一指挥。任何人员不得为抢进度、抢物料、抢设备而冒险进入危险区域。

## 6. 个人防护用品要求

### 6.1 基本佩戴要求

进入生产车间、仓库、设备间和装卸区域，应按区域要求佩戴相应劳动防护用品。基本要求如下：

1. 生产车间：安全鞋、工装、必要时佩戴护目镜和防割手套；
2. 机加工区域：护目镜、防割手套、耳塞或耳罩，不得佩戴围巾、长项链、松散袖口；
3. 装配区域：安全鞋、工装、防滑手套；
4. 仓储物流区域：安全鞋、反光背心，靠近叉车作业区域应注意车辆警示；
5. 空压机房和设备间：安全鞋、护目镜、必要时佩戴耳塞；
6. 化学品处理区域：防化手套、护目镜、防护围裙或面屏，按化学品安全说明书要求执行。

### 6.2 禁止事项

1. 不得穿拖鞋、凉鞋、高跟鞋进入生产、仓储和设备区域；
2. 不得在旋转设备附近佩戴易卷入物品；
3. 不得将劳保用品借给无关人员代替安全培训；
4. 不得以“短时间进入”“只是看一下”为理由不佩戴必要防护用品；
5. 不得使用破损、失效、明显污染或不适合当前作业的防护用品。

### 6.3 访客防护

外来访客进入生产区域前，应由接待部门进行安全提醒，并按区域要求发放访客防护用品。访客不得单独进入生产、仓库、设备、检测或施工区域。

## 7. 生产现场安全要求

### 7.1 通道与定置管理

1. 消防通道、安全出口、叉车通道、人员通道不得占用；
2. 物料、工装、托盘、周转箱应按定置区域摆放；
3. 生产现场不得堆放与当前作业无关的杂物；
4. 设备周边应保留必要维修空间；
5. 地面油污、水渍、铁屑、包装带等应及时清理。

### 7.2 设备操作

1. 员工只能操作经培训授权的设备；
2. 开机前应确认急停、护罩、安全门、报警灯、气源、电源和润滑状态；
3. 设备运行时不得拆卸防护罩、跨越安全线、伸手进入运动区域；
4. 发现异常振动、异响、焦糊味、冒烟、漏油、漏气、报警，应立即停机或通知班组长；
5. 设备故障未排除前，不得强行复位、屏蔽报警或连续重启。

### 7.3 标准作业

1. 员工应按作业指导书、工艺卡、检验标准和设备操作规程执行；
2. 不得擅自改变工装夹具、刀具参数、加工节拍、检测频次或安全防护方式；
3. 对临时返工、返修、挑选、加班赶产等非常规作业，应由班组长进行作业前安全说明；
4. 对新产品试制、新工艺导入、设备试运行，应由工程、质量、设备和安全相关人员共同确认风险。

## 8. 设备维修与能源隔离

### 8.1 维修工单要求

设备维修应通过设备维修工单或指定系统发起。工单应至少包含：

1. 设备名称、编号、所在区域；
2. 故障现象、报警代码、影响范围；
3. 是否影响生产、是否停机、是否存在安全风险；
4. 报修人、报修时间、现场联系人；
5. 维修责任人、处理过程、备件更换情况；
6. 维修完成确认和试运行结果。

### 8.2 能源隔离要求

维修、清洁、调试、故障排查和进入设备危险区域前，应根据设备风险执行能源隔离。能源类型包括但不限于电能、气压、液压、机械势能、热能、化学能和重力势能。

基本要求：

1. 停机后确认设备完全停止运动；
2. 切断主电源或控制电源，并挂牌提示；
3. 释放气压、液压或残余压力；
4. 对可能下落、移动、回弹的部件进行机械支撑或锁定；
5. 维修前由维修人员和现场负责人共同确认隔离状态；
6. 维修完成后，确认人员撤离、工具清点、防护复位，再恢复能源。

### 8.3 禁止行为

1. 未停机伸手处理卡料、缠绕、堵塞；
2. 未确认断电就打开配电柜或设备电控箱；
3. 用胶带、扎带、木块等方式临时屏蔽安全开关；
4. 为抢生产进度要求维修人员带电、带压、带负载作业；
5. 设备维修完成后未复位防护罩、安全门、急停和联锁即交付生产。

## 9. 空压机房与公用工程安全

### 9.1 空压机房基本要求

1. 空压机房应保持通风良好、地面清洁、无易燃杂物堆放；
2. 空压机、储气罐、干燥机、过滤器、管路和阀门应按设备部要求点检；
3. 压力表、安全阀、温度传感器和报警装置应保持有效；
4. 非设备部授权人员不得擅自调整压力参数、旁通保护装置或拆卸传感器；
5. 高温、高压、异常噪声、严重漏气、焦糊味、冒烟等情况应立即升级处理。

### 9.2 压缩空气使用

1. 不得使用压缩空气直接吹扫身体、衣物或头发；
2. 吹扫工件时应佩戴护目镜，防止铁屑、粉尘、液滴飞溅；
3. 临时气管应固定，避免绊倒、甩动或接头脱落；
4. 气管、接头、阀门发现破损、漏气、老化应及时更换；
5. 不得私自将压缩空气接入非批准设备或临时工装。

## 10. 电气安全与临时用电

### 10.1 电气操作要求

1. 配电柜、电控箱、设备电源线路由设备部授权电气人员管理；
2. 非授权人员不得打开配电柜、接线箱或改动电气线路；
3. 电气维修应执行断电、验电、挂牌、确认流程；
4. 发现电缆破损、插座松动、发热、异味、打火、漏电保护器频繁跳闸，应停止使用并报修；
5. 不得用湿手操作电气开关，不得在配电箱前堆放物料。

### 10.2 临时用电

临时用电适用于设备调试、施工、临时照明、临时检测等场景。使用前应提交临时用电申请，并由设备部确认。

临时用电要求：

1. 明确使用区域、使用时间、设备功率和责任人；
2. 使用符合要求的电缆、插头、漏电保护装置和配电箱；
3. 电缆不得横穿叉车通道，确需跨越通道时应设置防护；
4. 临时线路不得私拉乱接、不得多级插排串联；
5. 临时用电结束后应及时拆除，不得长期保留。

---

## 11. 消防安全

### 11.1 基本要求

1. 消防通道、安全出口、疏散指示、应急照明不得遮挡或占用；
2. 灭火器、消防栓、报警按钮、消防卷帘门周边不得堆放物料；
3. 易燃包装、油品、清洗剂、纸箱、木托盘应按规定区域存放；
4. 车间内不得私自使用电炉、热得快、大功率取暖设备；
5. 下班前应关闭非必要电源、气源、水源，清理可燃废弃物。

### 11.2 动火作业

动火作业包括焊接、切割、打磨产生火花、热风枪加热、明火烘烤等。动火前必须办理动火作业审批。

动火要求：

1. 明确动火地点、时间、作业人员、监护人和防火措施；
2. 清理周边可燃物，必要时设置防火毯或隔离板；
3. 配备有效灭火器材；
4. 动火期间监护人不得离岗；
5. 动火结束后至少观察 30 分钟，确认无余火、无烟气、无异常温升。

未经审批的动火作业属于三级及以上风险，应立即停止并报告安全环保部。

---

## 12. 仓储与叉车安全

### 12.1 仓储堆放

1. 物料应按区域、批次、状态和标识要求存放；
2. 货架不得超载，重物应放低层，轻物可放高层；
3. 托盘堆叠应稳定，不得倾斜、破损或超高；
4. 不合格品、待检品、合格品和报废品应明显区分；
5. 危险化学品、油品和易燃物品不得与普通物料混放。

### 12.2 叉车作业

1. 叉车只能由持证或经公司授权人员驾驶；
2. 叉车行驶应限速，转弯、倒车、通过交叉口应鸣笛或警示；
3. 叉车不得载人，不得超载，不得举升人员；
4. 人员不得在叉车货叉下方、举升货物下方或倒车盲区停留；
5. 装卸区域应设置警示，非相关人员不得进入。

发生叉车碰撞、货物跌落、险些撞人等事件，应按三级风险上报，不得私下处理。

---

## 13. 危险化学品与废弃物管理

### 13.1 化学品使用

1. 化学品应有清晰标签，标明名称、主要风险和责任部门；
2. 使用人员应了解化学品安全说明书中的防护、储存和泄漏处理要求；
3. 分装化学品必须使用合适容器，并重新张贴标签；
4. 不得使用饮料瓶、食品容器盛装化学品；
5. 清洗剂、润滑油、胶水、酒精等应远离火源和高温区域。

### 13.2 泄漏处理

1. 小范围泄漏且无明显火灾、中毒风险时，由现场人员佩戴防护用品后围堵、吸附、收集；
2. 泄漏范围扩大、气味刺激、人员不适或无法判断危险性时，应立即疏散并通知安全环保部；
3. 不得将未知化学品、油污或清洗液直接排入下水道；
4. 泄漏处置后的废抹布、吸附棉、污染容器应按危废要求收集。

### 13.3 危废管理

废油、废液、含油抹布、废过滤棉、废化学品容器等应放入指定危废暂存区域，由安全环保部统一安排处置。任何部门不得私自丢弃、转卖、混入生活垃圾或交由无资质单位处理。

---

## 14. 危险作业审批

以下作业必须事前审批，不得口头同意后直接实施：

1. 动火作业；
2. 高处作业；
3. 吊装作业；
4. 临时用电；
5. 受限空间作业；
6. 设备大修、改造、搬迁和试运行；
7. 外协施工；
8. 涉及停产、停线、拆除防护装置或关闭联锁的作业。

审批记录应包含作业内容、地点、时间、人员、风险识别、防护措施、监护人、应急措施和审批人。审批通过不代表风险自动消除，作业人员仍应在现场确认条件满足后方可开始。

---

## 15. 外协施工与访客管理

### 15.1 外协入场

外协单位入场前，业务对接部门应向安全环保部提交施工内容、施工时间、施工区域、人员名单、作业风险和联系人信息。外协人员必须完成入场安全告知后方可进入现场。

### 15.2 外协作业要求

1. 外协人员只能在批准区域作业；
2. 不得擅自接电、动火、登高、吊装或拆改设备；
3. 工具、材料、废料应按要求摆放和清理；
4. 外协作业现场应设置警戒或提示；
5. 公司对接人应对外协作业进行过程监督。

### 15.3 违规处理

外协人员存在未审批动火、无证操作、破坏防护装置、冒险作业、隐瞒事故等行为时，公司有权立即停止其作业，并视情况取消入场资格、追究合同责任或列入供应商负面清单。

---

## 16. 隐患排查与整改闭环

### 16.1 隐患来源

隐患可来自以下渠道：

1. 班组日常点检；
2. 部门自查；
3. 安全环保部专项检查；
4. 员工主动上报；
5. 客户审核、政府检查、第三方检查；
6. 事故、未遂事件和质量异常复盘。

### 16.2 隐患分级处理

1. 一般隐患：责任班组当班整改；
2. 较大隐患：责任部门 3 个工作日内完成整改或提交整改计划；
3. 重大隐患：立即采取临时控制措施，由部门负责人和安全环保部制定整改方案；
4. 紧急隐患：立即停工、疏散或隔离，待风险解除后方可恢复。

### 16.3 整改闭环

隐患整改必须包含责任人、整改措施、完成时间、验证人和验证结果。仅有“已通知”“已提醒”“后续注意”不能作为整改闭环。重复发生的隐患应进行原因分析，必要时修订作业指导书、培训材料或现场防呆措施。

---

## 17. 事故、事件与险肇报告

### 17.1 报告范围

以下情况必须报告：

1. 人员受伤、烫伤、割伤、夹伤、触电、坠落、砸伤；
2. 火灾、冒烟、爆燃、泄漏、异常气味；
3. 设备重大故障、异常停机、保护装置失效；
4. 叉车碰撞、货物坠落、险些撞人；
5. 危险作业未审批或审批措施未落实；
6. 未造成伤害但具有事故潜力的险肇事件；
7. 任何员工认为需要升级的安全异常。

### 17.2 报告时限

1. 紧急事件：立即口头报告，并启动应急处置；
2. 三级风险事件：30 分钟内报告部门负责人和安全环保部；
3. 二级风险事件：当班内报告部门主管；
4. 一级风险事件：当班内记录并整改。

### 17.3 禁止隐瞒

任何部门和个人不得隐瞒、迟报、漏报、谎报事故或险肇事件。不得以“没有受伤”“没有损失”“怕影响考核”为理由不报告。

---

## 18. 培训与授权

### 18.1 入职安全培训

新员工、实习人员、外协长期驻场人员进入现场前，应完成公司级安全培训。培训内容包括公司安全规则、风险分级、个人防护、应急疏散、事故报告和禁止行为。

### 18.2 岗位安全培训

员工上岗、转岗、复岗、使用新设备或参与新工艺前，应由所在部门进行岗位安全培训。岗位培训应覆盖设备风险、标准作业、异常处理、应急停止、劳保用品和现场逃生路线。

### 18.3 特殊岗位授权

叉车驾驶、电气维修、焊接切割、压力容器管理、化学品管理、吊装指挥等岗位必须具备相应资质或公司授权。未经授权不得独立操作。

---

## 19. 应急处置

### 19.1 基本处置原则

1. 优先保护人员生命安全；
2. 不盲目进入危险区域；
3. 不擅自移动受伤人员，除非现场存在更大危险；
4. 及时切断相关能源，但不得冒险操作；
5. 保留现场，便于事故调查；
6. 按公司应急预案和现场指挥要求行动。

### 19.2 常见场景初步响应

1. 发现火情：立即呼喊示警、按下报警按钮、报告安全环保部；在确保自身安全前提下使用灭火器初期扑救；
2. 人员触电：先切断电源，不得直接徒手接触触电人员；
3. 化学品刺激性气味：停止作业、远离源头、通知安全环保部；
4. 空压系统严重漏气：远离泄漏点，通知设备部，必要时隔离区域；
5. 叉车碰撞：停止车辆，保护现场，确认人员伤害并报告；
6. 设备异常高速运转或失控：按急停，撤离危险区域，通知设备部。

## 21. 与其他制度的衔接

1. 设备故障、维修、保养和空压机异常处理，按《设备维修手册_空压机》及设备部相关文件执行；
2. 生产过程中发现产品质量异常，应按《质量异常处理流程》执行，同时评估是否存在安全风险；
3. 因安全整改需要采购备件、劳保用品、维修服务或外协施工的，应按《采购管理制度》执行；
4. 因客户现场安全问题、供应商审核或设备安装调试产生差旅费用的，应按《差旅报销制度》执行；
5. 项目周报中涉及安全风险、隐患逾期、停线风险或外协施工风险的，应按《项目周报模板》要求列入风险与阻塞事项。

## 22. Agent 场景识别规则

为支持企业知识库与办公流程 Agent 对安全事项进行自动识别，以下关键词或场景应触发风险提示或流程升级。

### 22.1 应触发安全风险提示的关键词

1. 冒烟、明火、焦糊味、爆炸声、火花、异常发热；
2. 触电、漏电、打火、配电柜异响、跳闸；
3. 受伤、夹伤、割伤、砸伤、烫伤、昏迷、被困；
4. 漏油、漏气、泄漏、刺鼻气味、化学品洒落；
5. 防护罩缺失、安全门失效、急停失效、联锁被屏蔽；
6. 未审批动火、高处作业、吊装、临时用电、受限空间；
7. 叉车撞人、险些撞人、货物坠落、通道堵塞；
8. 空压机高温、高压、严重漏气、压力异常。

### 22.2 应触发人工升级的场景

1. 涉及人员受伤或疑似受伤；
2. 涉及火灾、触电、化学品泄漏或设备失控；
3. 涉及危险作业未经审批；
4. 涉及生产线停机、重大交付风险或客户现场安全风险；
5. 用户描述中包含“不确定是否安全”“能不能先凑合用”“临时绕过保护”等表达；
6. 文档中没有明确处理依据，但风险可能较高。

### 22.3 Agent 回答边界

当用户询问如何处理危险作业、事故应急、化学品泄漏、触电、火灾、设备带电维修等高风险事项时，Agent 应优先提示停止作业、远离危险源、通知责任部门或启动应急流程，不得鼓励用户自行冒险处理。对于需要现场专业判断的事项，Agent 应明确建议联系安全环保部、设备部或现场负责人确认。

## 23. 常见问答示例

### 23.1 设备防护罩松了还能继续生产吗？

不得直接继续生产。设备防护罩松动属于较大风险，应通知班组长和设备部确认。若防护罩失效或存在卷入、夹伤风险，应暂停设备运行，待防护恢复并确认后再生产。

### 23.2 空压机房有明显漏气声但生产还没停，是否需要报修？

需要报修。空压系统明显漏气可能导致压力不足、能耗升高和设备风险，应通过设备维修工单上报。若伴随高温、高压、严重漏油、报警或影响生产，应升级为重大风险处理。

### 23.3 只是临时焊一下支架，可以不走动火审批吗？

不可以。焊接、切割、打磨产生火花等均属于动火作业，必须办理动火审批，落实清理可燃物、配备灭火器材和现场监护等措施。

### 23.4 叉车通道临时堆放半小时物料可以吗？

原则上不允许。叉车通道和消防通道不得占用。确因卸货或转运需要短暂停留，应设置警示、安排人员看护，并尽快转移至定置区域。

### 23.5 发现同事未佩戴护目镜操作机加工设备怎么办？

应立即提醒其按要求佩戴，并通知班组长。若对方拒不整改或正在进行高风险作业，应要求暂停相关操作。
